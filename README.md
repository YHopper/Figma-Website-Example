Figma Landing Page Example
----------------------------------------
Hello, this is a landing page I made from a figma template provided by Coding Temple. The landing page is made entirely with HTML and CSS while also including personal information about me to make the landing page feel personal and believable as if the page was designed to be shown to a potential employer.

The landing page includes a homes page, a projects page, a recent works page, and a contact page. Each page includes a workable navigation bar, which also includes a clickable link to my LinkedIn page, along with the page's respective contents. 

Home ---> Includes a short bio, a picture of me, and the institutions I have worked with in my professional career so far. 

Projects ---> Includes projects I've worked on during my time in college and projects I'm currently working on.

Recent-Work ---> Includes projects/work that I'm currently working and devoting my time towards.

Contact ---> Includes interactable message prompts to make inputs. However, the contacts page is currently not connected to an external file/server for processing queries.
